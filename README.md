# 2 Roues Genève Market

Marketplace spécialisée dans la vente de motos et scooters à Genève.

## Fonctionnalités

- Comptes utilisateurs
- Comptes vendeurs
- Gestion des annonces
- Réservation de rendez-vous
- Recherche avancée
- Tableau de bord administrateur
- Responsive mobile
- Mode clair / sombre
- Interface Liquid Glass inspirée iOS 26

## Stack technique

Frontend:
- Next.js
- React
- Tailwind CSS

Backend:
- Supabase

Paiement:
- Stripe
- TWINT

Hébergement:
- Vercel
